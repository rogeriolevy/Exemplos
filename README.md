# BurguerLow | Estatística Aplicada à IA

Projeto acadêmico que apresenta um relatório visual de estatística descritiva aplicado ao processo de delivery de uma hamburgueria artesanal fictícia, com foco em análise de tempo de entrega, variabilidade e probabilidade.

## 📌 Descrição

A aplicação é uma página HTML simples que mostra:
- dados brutos de tempos de entrega
- distribuição de frequência por classes
- cálculos de média, moda, mediana, variância, desvio padrão e coeficiente de variação
- probabilidade de entrega em menos de 30 minutos
- gráficos de histograma e avaliações de clientes
- decisões estratégicas baseadas em indicadores estatísticos

## 🧩 Tecnologias

- HTML
- CSS
- JavaScript
- Chart.js (via CDN)

## 🚀 Como usar

1. Abra o arquivo `index.html` no navegador.
2. Navegue pelas seções do relatório usando o menu superior.
3. Clique em "Ver cálculo detalhado" para exibir os passos de cálculo.

## 🎯 Objetivo do projeto

Demonstrar a aplicação de conceitos de estatística descritiva em um caso prático de negócios, auxiliando na tomada de decisão para melhorar desempenho logístico e experiência do cliente.
